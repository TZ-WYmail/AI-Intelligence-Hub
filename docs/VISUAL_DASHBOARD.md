# 首页可视化与简报分页

2026-10-17更新。通知保持关闭，现有AI额度不变。

## 简报

归档日报与自定义简报统一支持每页5、10、20条，提供上一页、下一页及页码跳转；切换简报或每页条数时回到第一页。每页只渲染当前条目，标题、统计时间范围和说明仍保留。完整Markdown可单独下载，不会因分页而遗漏内容。

自定义简报生成结果保存在当前浏览器会话，翻页不会重新生成或丢失；重新生成后替换当前结果。旧日报按二级标题划分条目，旧自定义简报按顶层新闻链接划分，兼容已归档内容。缺内容时显示空状态，无空白分页。

## 全球热点

首页新增可拖拽旋转、滚轮缩放、悬停显示数值的3D地球仪，并可重置视角。地球轮廓在项目中本地打包，运行时不依赖地图密钥、外网瓦片、第三方地理编码或AI调用。底图来源与许可见dashboard/assets/README.md。

热区提供两种统计依据：

- **新闻明确提及的地区**：基于原始标题与来源摘要中的中英文地名规则。地区选择器可查看最近3篇命中报道和具体命中词。
- **数据源登记的地区**：仅使用来源country字段，不会根据域名或企业名称猜测。

位置是地区示意中心，光晕表示提及频次，不是事件精确地点或事实核验结果。提及地区不等于事件发生地；来源登记地区也不等于事件发生地。未知地区单列，不生成虚构坐标；一篇文章涉及多个地区时分别计数。地区名称、示意坐标及别名保存在config/regions.yaml，修改后重启API加载。

当前规则有遗漏和歧义，不覆盖所有地名、城市及事件语义。未来可新增经人工审核的事件地点字段，再提供经过核验的地理图层。

## 分析图表

支持最近24小时、7天、30天。所有图表按文章发现时间和系统显示时区统计，不把首次抓到的历史文章误说成刚发布的新闻。

- 行业关注度：多行业分类文章计数。
- 信息发现趋势：24小时范围按小时，其余按日；时间标签使用明确的分类轴，避免图表库错误推断年份。
- 重要性分布：按系统评分阈值统计，并保留尚未评分。
- 行业变化热力图、来源贡献前8名、新闻语言分布。

行业多标签及地区多提及的合计可能大于文章总量。来源贡献只统计成功入库文章，精确去重后的订阅重复项不另算。

为了保留旋转视角并避免重绘打断阅读，图表在切换范围或点击首页“刷新数据”时更新；顶部指标和最新新闻继续每20秒自动刷新。

API：GET /api/v1/stats/analytics?days=7，需要管理员鉴权，days范围1–30；只读聚合，不创建采集、分析或通知任务。按批读取窗口文章，较大历史数据量下需要进一步引入预聚合统计；初次实测1,216篇文章聚合约0.76秒，不能作为所有容量的性能承诺。

## 验证

51项自动测试通过，包含分页边界/每页条数重置、自定义简报跨翻页保留、地区未知值和嵌套地名、重复分类不重计、时间窗口、鉴权、图表空数据和视角配置。Ruff检查及格式检查通过。真实200条归档日报已在浏览器验证共40页、切换到第2页只显示第6–10条；浏览器实测地球拖拽旋转；正式部署结果另见visual-validation.json。
