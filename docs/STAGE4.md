# 第四阶段：事件报道关联与来源质量

日期：2026-10-17。通知发送保持关闭，DeepSeek每日20次/月估算20元配额不变。

## 事件关联

新入库文章分析前，查找发布时间前后72小时的其他来源初始报道，最多500篇。英文标题经大小写/标点规范化后要求词集合一致、字符相似度至少0.94；无可靠空格分词的标题要求字符相似度至少0.98。短标题、数字/否定措辞变化、发布时间推定、同来源和多事件候选歧义保持独立。

关联报道保留独立文章、来源、规则/AI结果，写入既有事件关联表，不删除历史证据。事件列表显示报道数并按最近更新排序；详情按发布时间展示来源时间线，明确标记“近似标题关联 · 未核实”。关联不改变验证状态、重要性、版本，不重复创建通知；关联文章的AI结果不覆盖初始事件摘要。

这只是保守的标题规则，仍可能漏关联/误关联，不代表完成语义去重和独立来源核验。历史事件暂不自动合并，重大后续进展版本管理留待后续。无需数据库结构迁移。标题超过600字符时跳过相似比较，限制外部输入的计算开销。

## 来源质量

`GET /api/v1/sources` 增加文章数、日期推定数、未来日期异常数、最近有效发布时间、内容年龄和新鲜度。未来超过5分钟和推定日期不进入最新发布时间统计。超过7天只是提示内容较旧，不等同采集故障；时间统计基于库中已保存文章，不保证覆盖订阅全部历史。

来源管理页使用中文列名，并同时展示采集成功率、最近成功和内容新鲜度。

## 真实来源验证

从FDA官方订阅目录取得实际链接，分别通过应用RSS采集器验证：

- FDA Press Releases：20条，最新发布时间2026-10-14 15:50:52 UTC。
- FDA Drugs：20条，最新发布时间2026-10-16 15:49:17 UTC。

两者均无需鉴权，采用每小时轮询，只用于个人订阅摘要与原文链接展示；未查到明确数字限额，不推断全文再分发权限。官方目录：https://www.fda.gov/about-fda/contact-fda/subscribe-podcasts-and-news-feeds

36氪官方快讯地址返回内容无法解析为RSS；NIH NIDCR目录指向的GovDelivery请求失败，均保存为禁用候选。工信部订阅目录本机请求失败，未编造订阅地址。候选保存在 `config/source_candidates.yaml`，后续全量验证会包含这些地址，不会因旧验证脚本遗漏它们。

来源单次验证不等于长期稳定性或端到端延迟保证。完整记录见 `source-validation.json`。

## 重启恢复

补齐AI请求中断状态：持久化任务重试时，旧的started记录改为interrupted，保留其费用预留和每日配额占用，因为无法断言供应商未计费。额度耗尽时继续规则模式。任务沿用既有过期租约恢复机制，默认最多等待300秒后重新领取。
