# 已知限制与后续工作

交付范围是 P0 主链路和少量 P1 基础接口，并非完整 SRS 所有条款均已完成。

1. GDELT 适配器及离线解析测试已实现；2026-10-16 本机请求收到错误，真实来源保持禁用。2026-10-24 受控复核单次返回 HTTP 200、50 条，但历史失败未归因、延迟接近 HTTP 阶段超时，仍禁用；返修后未重跑实网。NVIDIA Blog 超时，同样禁用。不绕过访问限制。
2. 22 个已验证订阅来自6个机构/平台（2026-10-17 历史快照；原 22 个启用配置未改，不代表当前全部在线），**不是22个独立机构**。2026-10-24 受控复核为 26 个中 19 个解析出条目、4 个合法空列表、3 个失败；19 个有条目也不等于当前可用。新增 FDA 新闻发布和药品动态；仍缺少中国政策、商业创业和更广泛医疗来源。36氪快讯 2026-10-24 返回 HTTP 200 但解析失败，NIH NIDCR 返回 404，均保持禁用；工信部订阅页本机访问失败，尚未取得可验证订阅URL。
3. 验证为单次快照，不证明长期稳定性或发现延迟；需 24–72 小时观察、测量来源延迟并逐项复审访问条款。2026-10-24 arXiv 四个已登记 feed 为空列表，官方未说明原因，故不归因周末、不推断“无内容”。默认只保存订阅自身提供的标题/摘要及元数据，不抓原文全文/PDF；原始 RSS 条目 30 天清理。日志文件本地开发未自动轮转，Docker 建议配置日志轮转。
4. 新文章现支持72小时内跨来源标题一致性关联，策略为**严格规范化标题相等**（2026-10-24 起，不再使用字符相似度阈值）。规范化只处理可确认为排版的差异：Unicode NFC（不做 NFKC 兼容折叠）、`lower()`（不做 casefold）、合并空白、去掉句末感叹号；词序、数字、正负号、币种、否定、问号、产品与技术标识全部保留。保留 72 小时窗口、同来源不合并、发布时间推定不参与、最多比较最新500篇初始报道；多候选命中时返回不关联。该策略宁可漏关联也不误合并，仍可能漏关联，也可能受大小写/排版歧义影响；不是语义去重、人工核验或事件后续版本管理。精确去重仍不额外保存重复条目。实体图谱和RAG未实现。详见 [EVENT_LINKING_REVIEW.md](EVENT_LINKING_REVIEW.md)。
5. 规则评分的独立来源确认维度固定为 0。模型评分独立保留在分析 JSON，不参与自动告警升级；verified 状态没有人工证据审核流程，所有自动事件为 unverified。可解释依据是简短评分维度，不保存隐藏推理。
6. 2026-10-24 本轮实现由 DeepSeek Harness 会话实际完成并委派，Codex 负责独立审查与实测；2026-10-17 的 DeepSeek 官方 API 单篇真实分析验证见 [STAGE2.md](STAGE2.md)。Telegram/飞书依用户要求保持关闭，真实消息投递未验证。飞书签名机器人暂未支持。
7. 单 Worker / Scheduler 运行；数据库唯一键、CAS 领取和过期租约保护任务，但多 Worker 的全局费用/域名限流不支持。增加并发前需持久化预算/域名租约，或迁移 PostgreSQL。现有 SQLite JSON 行业筛选使用 json_each，迁移 PostgreSQL 需替换该查询。
8. Worker 同步执行有超时的单任务。任务间隔可配置；不能承诺所有网络环境/坏源场景仍达成 P95 SLA。高优先通知/分析先于采集，单个正在执行的网络任务仍可能暂时占用 Worker。
9. 已有自动归档日报与手动时间范围汇总（最多200条，复用已有AI摘要、不新增模型调用）。研究型AI综合日报/周报、完整趋势分析、自动全文翻译、深度分析升级、数据导出CSV/PDF尚未实现。
10. 系统设置页面只读，修改服务器环境后重启。没有多用户、人工核验工作流、SSO、生产级分布式限流。API 请求限流为进程内；新建来源只验证 URL 安全/解析，访问条款仍需用户确认。
11. `ADMIN_API_KEY` 必须配置。默认仅 localhost；API 文档和健康探针公开，但业务数据全部鉴权。Streamlit 页面靠每次 API 调用认证，保留 Streamlit 默认 XSRF/CORS 防护。Docker 卷中数据和原始负载不是加密数据库。
12. Provider 的 API Base 与通知凭据来自管理员服务器配置，视为可信；来源 URL 的 SSRF 防护不允许私网和非标准端口，逐跳重验 DNS 并固定 IP/TLS SNI。HTTP 超时/体积上限防资源滥用，系统 DNS 的超时依赖宿主解析器。机器网络边界仍需防火墙控制。
13. 关键词/来源关联使用 JSON 列简化单用户 MVP；非独立关系表。字面全文搜索不是 FTS/向量检索。当前仅 UTC 日/月预算，无实际供应商账单对账；失败调用保守计入预留预算。
14. 尚未执行 24 小时稳定性观察；本机系统是 Ubuntu 26.04.1，Ubuntu 24.04 LTS 需另行验证。Python 本地 3.12.14，容器实际版本在实测报告记录。

15. 地球热区使用标题/来源摘要地名匹配或来源登记地区，不是事件精确地点。当前27个地区配置有遗漏与歧义，未知地区不绘图；需要WebGL浏览器显示3D地球。分析图表按发现时间统计，历史窗口较大时仍需预聚合优化。详见VISUAL_DASHBOARD.md。
