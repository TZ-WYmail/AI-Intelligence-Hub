# 第三阶段：连续阅读、个人清单、每日简报与自动备份

日期：2026-10-17。通知发送保持关闭，现有 DeepSeek 配额不变。

## 阅读体验

- 详情改为完整阅读页，阅读时隐藏列表页标题/刷新栏，减少滚动与弹窗遮挡。
- 返回列表、上一篇/下一篇；返回后保留筛选与页码。连续导航范围为当前一页；可返回列表继续翻页。
- 阅读字号16/18/20/22px，紧凑/适中/宽松宽度；偏好在当前浏览器会话内保留。
- “中文速读 / 原文摘要 / 来源与处理”分栏；先展示中文概述、事实提取、AI 影响，技术证据折叠。
- 原始来源、发布时间、阅读时长清晰展示；可打开原文、下载阅读笔记。
- 全部/未读/我的收藏/已读四种清单，阅读自动记已读，可手动改回未读。状态保存到数据库并在服务重启后保留。
- 长摘要缩短为预览，卡片标题和元信息分层；可切换紧凑列表，按按钮翻页，空页自动回到第一页。
- 所有源站文字进入自定义 HTML 前均转义，避免外部 HTML/图片/脚本注入；源站只提供摘要时明确标注，未抓取或假装提供全文。

## 日报

- 由持久化 Worker 任务生成，默认每天上海时间08:00生成前一日简报；“简报”页可手动生成昨日简报。
- 时间范围按来源发布时间过滤，结束时刻不包含，缺可靠发布时间的文章明确提示使用发现时间。
- 从已处理文章中按规则重要性选取最多200条；同时显示完整匹配数量，保留来源链接与生成时间。
- 复用已有 AI 摘要，无新增模型调用；未分析文章使用来源摘要，不声称完成综合趋势研究或 AI 周报。
- 日报保存数据库，按时间范围唯一约束防重复。可查看历史归档、下载 Markdown。自定义时间范围汇总接口继续可用。

## 备份

- 默认每24小时自动在线备份 SQLite；初次启动无备份记录时会立即入队一次。
- 保存到 Docker 数据卷 `data/backups`，仅轮换本服务生成的备份，默认保留最近7份。
- 文件写入前设置0600权限，先写临时文件并检查SQLite完整性，再发布为正式备份；保留成功/失败任务与指标。
- 备份与日报均进入数据库任务队列，服务重启不会丢弃已排队任务；失败有上限重试。
- 备份仍在同一机器/卷，应另行复制到受控的异机存储，才能抵御整机/磁盘故障。

配置项见 `.env.example`：BACKUP_ENABLED、BACKUP_INTERVAL_HOURS、BACKUP_KEEP_COUNT、BACKUP_DIRECTORY、DAILY_DIGEST_ENABLED、DAILY_DIGEST_HOUR。

## API / 数据迁移

- Alembic 0002：文章增加 read_at / bookmarked，新增 digests 表；升级保留历史文章。
- `PATCH /api/v1/articles/{id}/reading`：设置阅读/收藏。
- `GET /api/v1/articles?reading_state=all|unread|read|saved`。
- `GET /api/v1/reports`、`GET /api/v1/reports/{id}`：归档日报。
- `POST /api/v1/reports/daily`：入队昨日简报，已有归档时直接返回。
