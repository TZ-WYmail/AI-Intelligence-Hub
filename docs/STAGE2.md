# 第二阶段：DeepSeek 接入与新闻阅读改进

2026-10-17，基于现有 MVP 继续推进；本阶段不启用通知发送。

## 已交付

- 本机 `.env` 配置 DeepSeek 官方 API；密钥不写入源文件/文档/测试/镜像，也不提交 GitHub。
- Provider 可选 `AI_THINKING_MODE=provider_default|disabled|enabled`。默认不发送厂商扩展；DeepSeek 当前配置 disabled，使用低成本非思考结构化输出。
- 输出被截断（finish_reason=length）时拒绝当作成功 JSON，保留规则结果和重试机制。
- 对正式数据库中一篇真实新闻完成 DeepSeek 调用、Schema 校验、分析持久化与用量记录。
- 新闻列表展示已成功的 AI 中文摘要、模型与未核验标识；原文摘要、事实提取、规则评分和 AI 潜在影响在详情中分开展示。
- 搜索涵盖原始标题/摘要/内容，以及成功 AI 分析中的中文摘要和影响分析。
- 支持筛选“已有 AI 分析 / 暂无 AI 分析 / AI 等待重试”。筛选变化自动回到第一页，空列表给出提示。
- 列表按发现时间优先；详情点击后加载。数据库列表用批量关联取事件/分析，避免每条文章逐个查询事件和每页逐个请求详情。
- 新增 `POST /api/v1/articles/{id}/analyze`，通过现有持久化队列分析历史文章。AI 未启用时拒绝；重复在途任务不重复入队，已成功结果复用，不重复收费。
- 自动化测试隔离本机真实凭据，不因 `.env` 启用 AI 而调用付费模型。

## 实测

- 32 项 pytest 测试通过，Ruff 检查/格式检查通过。
- 单篇真实 DeepSeek：约 2.97 秒，输入 749 / 输出 401 Token；中文摘要 77 字，验证状态保持 unverified。
- 按当前保守配置单价估算费用 0.01952 元；**不是 DeepSeek 账单金额**。当前仍按输入10/输出30元每百万 Token 估算，未按供应商缓存、峰谷和汇率逐项对账。
- 正式 API 验证中文摘要搜索、已分析筛选、重复分析复用与通知关闭；机器可读结果见 stage2-validation.json。
- Docker 更新前已在线备份正式数据库到数据卷中的 `before-stage2.db`；命名卷保留。

## 当前运行配置

- 模型：deepseek-flash；Base URL：https://api.deepseek.com；非思考模式；超时60秒；输出上限1800 Token。
- 新文章自动分析开启；UTC 每天最多20次调用（失败尝试也计入），每月估算预算20元。达到额度后继续采集、规则分类评分和查看。
- 历史文章不会自动整库重跑；“实时新闻 → 暂无 AI 分析 → 查看详情与分析 → 分析这篇文章”可按需加入队列。
- Telegram、飞书都关闭；本阶段未发送任何真实通知。
